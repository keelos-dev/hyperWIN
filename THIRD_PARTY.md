# Third-party code in hyperWIN

## IronRDP

- Source: https://github.com/Devolutions/IronRDP
- License: MIT OR Apache-2.0 (the MIT text is in `LICENSE-IronRDP-MIT`)
- Used as a library, from two revisions (put into `vendor/` by `tools/vendor-ironrdp.sh`):
  - `hyperwin.exe` and `hyperwin-app.exe`: rev `8f9bf5b8102dd3c4cdb4841939d4dbba35c7bff8` (the
    pin of keelOS's keel-rdp and of hyperMAC) with `ironrdp-keel.patch` (keelOS's patch for
    keel-rdp: CredSSP looks the password or its NT hash up by the user name; Hybrid security
    that also accepts TLS-only clients; application-defined dynamic channels, `keelOS::Video`;
    reliable UDP beside TCP), `ironrdp-hypermac.patch` (hyperMAC's: a redraw the client asks
    for makes the server send the next picture whole) and `ironrdp-hyperwin.patch`
    (hyperWIN's: the VM named beside the account in an NLA login; the frame-buffer channel of
    a VM's console for a process without a logon SID).
  - `hyperwin-guest.exe` (the helper hyperWIN puts into Windows guests, `guest/`): rev
    `d5e70f02b670dbe79ad7ef47203bfa82d32c16f4` with `ironrdp-krdp.patch` (kRDPclient's patch),
    for its Windows clipboard with files (`ironrdp-cliprdr-native`) and the clipboard channel.

## Rust crates

Every other dependency comes from crates.io under its own license. `THIRD_PARTY-crates.txt`
(of `Cargo.lock`: `hyperwin.exe`, `hyperwin-app.exe`) and `THIRD_PARTY-guest-crates.txt` (of
`guest/Cargo.lock`: `hyperwin-guest.exe`) list each crate with its license and the license and
notice texts it ships (generated by `tools/third-party.py` with keelOS's license checker; each
file names the `Cargo.lock` it is of).

## kRDPclient

A release carries `krdpclient.exe` (the app's Console button shows a VM's screen with it): the
published program of https://github.com/keelos-dev/kRDPclient-releases, unchanged, a program
of its own and not built from this repository. `kRDPclient-RELEASE.txt` names the release it
is; its third-party notices are the `kRDPclient-*` files beside it (`kRDPclient-THIRD_PARTY.md`
and the files that one names, each with `kRDPclient-` before its name).

## Windows

The hypervisor, the Host Compute System and Host Compute Network, the virtual machine worker
process, Media Foundation's H.264 encoders and the guests' own drivers are parts of Windows
and are not distributed with hyperWIN. A guest's display driver files are the host's own,
copied from the host's driver store into the guest on the same PC.

Not distributed with hyperWIN, provided by the user: the systems' installers (ISO files).
